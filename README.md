Our digital wellness application is Present Minds, a time management application specifically designed for users with ADHD.
Targeting a younger audience, it features a vibrant colour scheme and a simple design to make it engaging and easy to use.
The primary goal of this project is to streamline time management for individuals who struggle with it and to support parents and carers in helping their children develop this essential skill. 

Our features are:
•	Time-based reminders that display system notifications
•	Time-based restrictions that close restricted apps
•	ADHD Information Page
•	App runtime tracking and graph displays
•	Comprehensive user account functionality for personal or parental use
